# HTML Visual Editor

`index.html`을 불러와 텍스트·색상·레이아웃을 **코드 없이 화면에서 바로** 수정하고, 수정된 파일을 내려받는 브라우저 기반 편집 도구입니다.

설치나 서버가 필요 없습니다. HTML 파일 하나를 브라우저로 열면 바로 쓸 수 있습니다.

### ▶ [바로 실행하기](https://utaeu.github.io/html-visual-editor/)

링크를 누르면 브라우저에서 바로 열립니다. 불러온 `index.html`은 브라우저 안에서만 읽히고 서버로 전송되지 않습니다.

## 빠른 시작

1. 위의 **바로 실행하기** 링크를 누릅니다. (오프라인에서는 `editor-standalone.html`을 더블클릭해 브라우저로 엽니다. Chrome 권장)
2. **index.html 파일 열기** 버튼을 누르거나, 파일을 가운데 영역으로 드래그합니다.
   CSS·이미지·스크립트 파일이 따로 있는 프로젝트라면 **폴더 열기**로 폴더를 통째로 열거나 폴더를 드래그합니다.
3. 미리보기에서 수정할 요소를 클릭하고, 오른쪽 패널에서 값을 바꿉니다.
4. **내보내기(다운로드)** 를 누르면 `edited-index.html`로 저장됩니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 폴더 열기 | 프로젝트 폴더를 열면 연결된 CSS·JS·이미지까지 불러와 실제 모습대로 미리보기. 폴더 안 다른 HTML 페이지는 툴바 목록에서 전환 |
| 요소 선택 | 미리보기에서 클릭하거나 왼쪽 **요소 트리**에서 선택 |
| 요소 트리 접기 | 왼쪽 요소 트리는 기본으로 접혀 있음. `»` 띠를 누르면 펼치고 `«`로 다시 접음 (마지막 상태를 기억) |
| 복수 선택 | `Ctrl`(또는 `Shift`)+클릭, 툴바의 **복수 선택** 버튼, 또는 미리보기를 드래그해 범위 지정 |
| 일괄 글자 크기 | 여러 요소를 선택하면 각각 −1 / +1px씩 조절하거나, 숫자를 입력해 모두 같은 크기로 지정 |
| 내용 편집 | 선택한 요소의 텍스트 수정. **줄바꿈** 버튼이나 `Enter` 키로 줄을 바꾸면 `<br>`로 저장 |
| 색상 | 배경색, 텍스트 색상 (해제 버튼으로 원래대로) |
| 텍스트 | 글자 크기, 글씨체(직접 입력 가능), 굵기, 정렬 |
| 위치 / 크기 | 너비, 높이, 배치 방식(static·relative·absolute), top·left |
| 여백 | margin / padding 상·우·하·좌 개별 지정 |
| 형태 | 모서리 둥글기, 테두리(두께·종류·색상), 그림자 |
| 복제 / 삭제 | 기존 요소를 복사해 바로 뒤에 붙여넣기, 또는 삭제 |
| 되돌리기 / 다시하기 | 모든 편집(스타일·텍스트·복제·삭제)을 되돌릴 수 있음 |
| 편집 / 보기 모드 | 보기 모드에서는 페이지의 버튼·스크립트가 실제로 동작 |
| 반응형 미리보기 | 데스크톱 / 태블릿(768px) / 모바일(375px) 폭으로 확인 |
| 내보내기 | 편집 도구가 붙인 표식을 모두 제거한 깨끗한 HTML로 저장 |

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl` + `click` | 요소 복수 선택 |
| `Ctrl` + `Z` | 되돌리기 |
| `Ctrl` + `Y` / `Ctrl` + `Shift` + `Z` | 다시하기 |
| `Ctrl` + `D` | 선택한 요소 복제 |
| `Delete` / `Backspace` | 선택한 요소 삭제 |
| `Ctrl` / `Shift` + 클릭 | 선택 목록에 요소 추가·제거 |
| `Esc` | 선택 모두 해제 |

텍스트 입력 칸에 커서가 있을 때는 단축키가 동작하지 않습니다. 글자를 지우다가 요소가 삭제되는 일을 막기 위해서입니다.

## 알아두면 좋은 점

- **파일 하나만 열면 외부 파일은 보이지 않습니다.** `assets/style.css`, `img/photo.jpg`처럼 상대 경로로 연결된 파일은 HTML 파일만으로는 읽을 수 없어 배경·사진이 빠지고 글자만 보입니다. 이때는 **폴더 열기**로 프로젝트 폴더를 여세요. (파일 하나만 열었는데 외부 파일이 있으면 안내 메시지가 뜹니다.)
- **폴더로 열어도 내보내는 것은 편집한 HTML 한 개입니다.** 경로는 원래 표기(`img/photo.jpg` 등) 그대로 저장되므로, 받은 파일을 원래 위치에 덮어쓰면 됩니다. 페이지를 바꾸면 내보내지 않은 수정 내용은 사라집니다.
- **폴더로 열어도 일부 스크립트 기능은 다르게 보일 수 있습니다.** 미리보기 문서는 주소가 없어서, 현재 파일 이름(`location`)으로 메뉴를 표시하거나 `fetch()`로 다른 파일을 읽는 스크립트는 실제 사이트와 다르게 동작할 수 있습니다.
- **수정 내용은 인라인 스타일로 저장됩니다.** 예: `<div style="color: #ff0000;">`
- **하위 요소가 있는 요소는 텍스트를 직접 고칠 수 없습니다.** 안쪽 요소를 선택해서 수정하세요. (하위 구조가 통째로 지워지는 것을 막기 위한 제한입니다. 줄바꿈 `<br>`만 있는 요소는 예외로 편집할 수 있습니다.)
- **복제하면 `id`도 같이 복사됩니다.** 같은 `id`가 두 개가 되므로 필요하면 내보낸 뒤 수정하세요. 이 경우 화면에 안내 메시지가 뜹니다.
- **드래그 범위 선택은 글자를 직접 담은 요소만 잡습니다.** 레이아웃용으로 감싸는 `div` 같은 요소는 빠집니다. 필요하면 `Ctrl`+클릭으로 더하세요.
- **복수 선택 상태에서는 글자 크기만 일괄로 바꿀 수 있습니다.** 다른 속성은 요소를 하나만 선택해서 수정하세요.
- **자동 저장되지 않습니다.** 새로고침하거나 창을 닫기 전에 내보내기를 해주세요.

## 파일 구성

```
editor.html              편집기 화면 구조
editor.css               편집기 스타일
editor.js                편집기 동작 로직
editor-standalone.html   위 3개를 합친 단일 파일 (build.py로 생성)
build.py                 단일 파일 생성 스크립트
index.html               GitHub Pages 진입점 (편집기로 이동만 함)
.nojekyll                GitHub Pages가 파일을 가공 없이 그대로 배포하도록 지정
```

`main` 브랜치에 push하면 GitHub Pages 사이트가 자동으로 갱신됩니다.

## 개발

소스는 `editor.html`, `editor.css`, `editor.js` 세 파일입니다. 수정한 뒤 단일 파일 버전을 다시 만드세요.

```bash
python build.py            # editor-standalone.html 재생성
python build.py --check    # 동기화 여부만 확인 (다르면 종료 코드 1)
```

> `editor-standalone.html`은 생성되는 파일이므로 직접 수정하지 마세요. 다음 빌드 때 덮어써집니다.

개발 중에는 `editor.html`을 브라우저로 열어 확인하면 됩니다. Python 3.7 이상이 필요합니다.
