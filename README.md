# HTML Visual Editor

`index.html`을 불러와 텍스트·색상·레이아웃을 **코드 없이 화면에서 바로** 수정하는 편집 도구

### ▶ [바로 실행하기](https://utaeu.github.io/html-visual-editor/)

## 빠른 시작

1. 위의 **바로 실행하기** 링크를 클릭. (파일을 다운 받았을 경우 `editor-standalone.html` 사용)
2. **index.html 파일 열기** 버튼을 누르거나, 파일을 드래그 앤 드롭
   index.html을 넣었는데 깨지는 경우 -> **폴더 열기**로 폴더를 통째로 열거나 폴더를 드래그 앤 드롭 
3. 수정할 요소를 클릭하고, 오른쪽 패널에서 요소 수정
4. **내보내기(다운로드)** 를 누르면 `edited-index.html`로 파일 저장
5. `edited-index.html`를 기존 폴더에 있던 `index.html` 로 교체

## 주요 기능

| 기능 | 설명 |
|---|---|
| 폴더 열기 | `index.html` 만 넣었는데 깨지는 경우에는 폴더 전체 업로드 |
| 요소 선택 | 미리보기에서 클릭하거나 왼쪽 **요소 트리**에서 선택 |
| 복수 선택 | `Ctrl`(또는 `Shift`)+클릭, 툴바의 **복수 선택** 버튼, 또는 미리보기를 드래그해 범위 지정 |
| 일괄 글자 크기 | 여러 요소를 선택하면 각각 −1 / +1px씩 조절하거나, 숫자를 입력해 모두 같은 크기로 지정 |
| 내용 편집 | 선택한 요소의 텍스트 수정. **줄바꿈** 버튼이나 `Enter` 키로 줄바꿈 |
| 색상 | 배경색, 텍스트 색상 (해제 버튼으로 원래대로) |
| 텍스트 | 글자 크기, 글씨체(직접 입력 가능), 굵기, 정렬 |
| 위치 / 크기 | 너비, 높이, 배치 방식(static·relative·absolute), top·left |
| 여백 | margin / padding 상·우·하·좌 개별 지정 |
| 형태 | 모서리 둥글기, 테두리(두께·종류·색상), 그림자 |
| 복제 / 삭제 | 기존 요소를 복사해 바로 뒤에 붙여넣기, 또는 삭제 |
| 사진 추가 | 이미지 파일을 선택한 요소 뒤에 삽입(선택하지 않으면 본문 끝). 부모 폭을 넘지 않고 비율 유지. HTML에는 경로(`images/사진.jpg` 등)로 연결 |
| 사진 바꾸기 | 사진(`<img>`)을 선택하면 표시. 칸 크기·비율은 그대로 두고 사진만 교체(넘치는 부분은 잘림) |
| 요소 위치 | 선택한 요소(사진·글·상자 등)를 **끌어서** 다른 요소의 앞뒤로 옮기기(파란 선이 놓일 자리), **↑ 앞으로 / ↓ 뒤로** 버튼으로 한 칸씩 이동 |
| 사진 정렬 | 사진을 **좌·중·우**로 배치 |
| 되돌리기 / 다시하기 | 모든 편집(스타일·텍스트·복제·삭제·사진·이동)을 되돌릴 수 있음 |
| 편집 / 보기 모드 | 보기 모드에서는 페이지의 버튼·스크립트가 **실제로 동작** |
| 반응형 미리보기 | 데스크톱 / 태블릿(768px) / 모바일(375px) 폭으로 확인 |
| 내보내기 | 편집 도구가 붙인 표식을 모두 제거한 깨끗한 HTML로 저장 |

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl` + `Z` | 되돌리기 |
| `Ctrl` + `Y` / `Ctrl` + `Shift` + `Z` | 다시하기 |
| `Ctrl` + `D` | 선택한 요소 복제 |
| `Delete` / `Backspace` | 선택한 요소 삭제 |
| `Ctrl` / `Shift` + 클릭 | 요소 복수 선택 |
| `Esc` | 선택 모두 해제 (요소를 끄는 중이면 옮기기만 취소) |

텍스트 입력 칸에 커서가 있을 때는 단축키가 동작하지 않습니다. 글자를 지우다가 요소가 삭제되는 일을 막기 위해서입니다.

## 알아두면 좋은 점

- **파일 하나만 열면 외부 파일은 보이지 않습니다.** `assets/style.css`, `img/photo.jpg`처럼 상대 경로로 연결된 파일은 HTML 파일만으로는 읽을 수 없어 배경·사진이 빠지고 글자만 보입니다. 이때는 **폴더 열기**로 프로젝트 폴더를 여세요. (파일 하나만 열었는데 외부 파일이 있으면 안내 메시지가 뜹니다.)
- **폴더로 열어도 내보내는 것은 편집한 HTML 1개 입니다.** 경로는 원래 표기(`img/photo.jpg` 등) 그대로 저장되므로, 받은 파일을 원래 위치에 덮어쓰면 됩니다. **내보내기**를 하지 않으면 진행사항이 저장되지 않습니다.
- **폴더로 열어도 일부 스크립트 기능은 다르게 보일 수 있습니다.** 미리보기 문서는 주소가 없어서, 현재 파일 이름(`location`)으로 메뉴를 표시하거나 `fetch()`로 다른 파일을 읽는 스크립트는 실제 사이트와 다르게 동작할 수 있습니다.
- **수정 내용은 인라인 스타일로 저장됩니다.** 예: `<div style="color: #ff0000;">`
- **추가하거나 바꾼 사진은 HTML에 경로로만 연결됩니다.** HTML 파일이 커지지 않는 대신, 사진 파일은 직접 복사해야 합니다. 사진을 넣을 때와 내보낼 때 복사할 위치(예: `images/사진.jpg`, HTML 파일 기준)를 알려 줍니다.
  - 경로는 페이지의 기존 사진이 가장 많은 폴더로 정합니다. 기존 사진이 없으면 `images/`, 사진 바꾸기는 원래 사진과 같은 폴더를 씁니다.
  - 폴더로 열었을 때 **그 폴더 안에 있는 사진을 고르면** 그 파일을 그대로 가리키므로 복사할 필요가 없습니다. 폴더에 같은 이름의 다른 파일이 있으면 `사진-1.jpg`처럼 이름을 바꿔 덮어쓰지 않게 합니다.
- **사진 바꾸기는 레이아웃을 유지합니다.** 원래 칸의 비율(`aspect-ratio`)을 고정하고 `object-fit: cover`로 새 사진을 칸에 맞춥니다. 비율이 다른 사진은 가장자리가 잘립니다. 원래 사진이 깨져 보이던 경우(파일만 연 경우 등)에는 칸 크기를 알 수 없어 사진 크기대로 표시합니다.
- **요소 위치는 HTML 안의 순서로만 바꿉니다.** 마우스로 픽셀 위치를 지정하는 자유 배치는 일부러 넣지 않았습니다. 자유 배치는 주변 요소를 겹치게 하거나 모바일 화면에서 위치가 어긋나기 때문입니다. 옮긴 요소는 주변 요소와 함께 자연스럽게 다시 배치됩니다.
  - 끌어서 옮기기는 **이미 선택된 요소의 안쪽**을 누른 채 끌 때 동작합니다. 카드처럼 속이 다른 요소로 채워진 상자도 안쪽 아무 곳이나 잡고 끌면 상자 전체가 옮겨집니다. 끌지 않고 그냥 클릭하면 안쪽 요소가 선택됩니다.
  - 선택된 요소 안에서 시작한 드래그는 옮기기가 되므로, 그 안에서 범위 선택을 하려면 먼저 `Esc`로 선택을 해제하세요.
  - 요소 위에 놓으면 그 요소의 앞이나 뒤로 들어갑니다(가로로 나열된 곳에서는 왼쪽·오른쪽 기준). 문단 글자 한가운데처럼 요소 안쪽에는 넣을 수 없습니다. 미리보기 위·아래 끝으로 끌면 자동으로 스크롤됩니다.
  - **HTML 구조가 깨지는 자리에는 놓을 수 없습니다.** 파란 선이 안 보이는 곳이 그런 자리입니다.
    - 상자·문단 같은 블록 요소는 문단·제목·버튼 등 글자용 요소 안에 넣을 수 없습니다. 가리킨 곳이 그런 자리면 감싸는 문단의 앞뒤로 자동으로 옮겨 잡습니다.
    - 목록 항목(`li`)은 목록 안에서만, 표의 행·칸(`tr`·`td`)은 표 안에서만, `option`은 선택 상자 안에서만 옮길 수 있습니다.
    - 자기 자신 안이나 링크 안의 링크, 버튼 안의 버튼, 폼 안의 폼에는 넣을 수 없습니다.
  - **옮기면 모양이 바뀔 수 있습니다.** 사이트 CSS가 "카드 안의 제목"처럼 위치에 따라 모양을 정해 두었다면, 다른 곳으로 옮긴 요소는 모양이 달라집니다. 결과가 이상하면 `Ctrl`+`Z`로 되돌리세요.
  - **정렬**은 사진을 한 줄 전체로 두고 좌우 여백(margin)으로 왼쪽·가운데·오른쪽에 배치합니다. 사진의 기존 좌우 여백은 덮어쓰고, 해제하면 사이트 CSS 값으로 돌아갑니다. 가로로 나열된 영역(flex) 안에서는 옆 요소까지 밀려나므로 정렬 버튼이 꺼집니다.
- **목록·표 안에서 사진을 추가하면** `<ul>`·`<tr>` 같은 구조에 바로 넣지 않고, 칸(`<li>`·`<td>`) 안쪽 끝에 넣습니다. 가로로 나열된 영역(flex·grid) 안에 넣으면 칸이 하나 늘어 배치가 바뀔 수 있으니 결과가 이상하면 `Ctrl`+`Z`로 되돌리세요.
- **하위 요소가 있는 요소는 텍스트를 직접 고칠 수 없습니다.** 안쪽 요소를 선택해서 수정하세요. (하위 구조가 통째로 지워지는 것을 막기 위한 제한입니다. 줄바꿈 `<br>`만 있는 요소는 예외로 편집할 수 있습니다.)
- **복제하면 `id`도 같이 복사됩니다.** 같은 `id`가 두 개가 되므로 필요하면 내보낸 뒤 수정하세요. 이 경우 화면에 안내 메시지가 뜹니다.
- **드래그 범위 선택은 글자를 직접 담은 요소만 잡습니다.** 레이아웃용으로 감싸는 `div` 같은 요소는 빠집니다. 필요하면 `Ctrl`+클릭으로 더하세요.
- **복수 선택 상태에서는 글자 크기만 일괄로 바꿀 수 있습니다.** 다른 속성은 요소를 하나만 선택해서 수정하세요.
- **자동 저장되지 않습니다.** 새로고침하거나 창을 닫기 전에 내보내기를 해주세요.

## 파일 구성

```
editor.html              편집기 화면 구조
editor.css               편집기 스타일
editor.js                편집기 동작 로직
editor-standalone.html   위 3개를 합친 단일 파일 (build.py로 생성)
build.py                 단일 파일 생성 스크립트
index.html               GitHub Pages 진입점 (편집기로 이동만 함)
.nojekyll                GitHub Pages가 파일을 가공 없이 그대로 배포하도록 지정
```

`main` 브랜치에 push하면 GitHub Pages 사이트가 자동으로 갱신됩니다.

## 개발

소스는 `editor.html`, `editor.css`, `editor.js` 세 파일입니다. 수정한 뒤 단일 파일 버전을 다시 만드세요.

```bash
python build.py            # editor-standalone.html 재생성
python build.py --check    # 동기화 여부만 확인 (다르면 종료 코드 1)
```

> `editor-standalone.html`은 생성되는 파일이므로 직접 수정하지 마세요. 다음 빌드 때 덮어써집니다.

개발 중에는 `editor.html`을 브라우저로 열어 확인하면 됩니다. Python 3.7 이상이 필요합니다.
