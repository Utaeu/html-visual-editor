요소 트리

파일을 열면 요소 트리가 표시됩니다.

여기로 index.html 또는 프로젝트 폴더를 드래그하거나
위의 버튼을 눌러 열어주세요

CSS·이미지·스크립트 파일이 따로 있다면 폴더 열기로 열어야 화면이 제대로 보입니다.

보기 모드 — 페이지가 실제로 동작합니다. 원하는 화면을 띄운 뒤 편집 모드로 돌아오세요.

속성 편집

선택된 요소 없음

요소를 선택하면 이곳에 편집 옵션이 표시됩니다.
Ctrl+클릭하거나 화면을 드래그해 범위를 지정하면 여러 요소를 한 번에 선택할 수 있습니다.

일괄 편집

px

−1 / +1은 요소마다 현재 크기에서 1px씩 바꿉니다. 숫자를 직접 입력하면 모든 요소가 같은 크기가 됩니다.

위치

순서
사진 정렬

가로로 나열된 영역 안에서는 정렬을 쓸 수 없습니다. 옆 요소의 배치까지 바뀌기 때문입니다. 순서 이동을 사용하세요. (이미 정렬된 사진은 파란 버튼을 눌러 해제할 수 있습니다)

선택한 요소의 안쪽 아무 곳이나 누른 채 끌면 다른 요소의 앞뒤로 옮길 수 있습니다. 파란 선이 놓일 자리이고, 선이 안 보이는 곳에는 놓을 수 없습니다.
